# Layer Lens — Live2D PSDチェッカー

Live2D Cubism 用の PSD / CLIP STUDIO（.clip）ファイルを、モデリング前に検品するためのブラウザツールです。
**すべての処理はブラウザの中で行われ、ファイルが外部に送信されることはありません。**

## 主な機能

- **データ診断**：キャンバス外・レイヤーマスク・クリッピング・命名規則違反・同名レイヤー・空白レイヤー・特殊なブレンドモード・レイヤー効果 など
- **マスクの適用 / 削除**、**レイヤー名の変更**（ダブルクリック / F2）をして修正版 PSD を保存
- **命名ツール**：フォルダー内の連番命名、R / L・線画 / 塗りなどのスタンプ、スペース整理、同名に連番、名前の置換、元に戻す（Ctrl+Z）
- **.clip → PSD 変換**：PSD で見た目や情報が変わるレイヤー（加算(発光)・画像素材・3D・用紙など）を警告
- **プレビュー**：選択レイヤーの位置表示、クリックで拡大表示
- **差分情報 / 階層構造 / チェックレポート**のコピー
- PWA 対応：インストールするとオフラインでも使え、PSD / CLIP をアプリで直接開けます

## 使い方

公開ページを開いて、PSD または .clip をドロップするだけです。
ローカルで使う場合は `index.html` をブラウザで開いても動きます（オフライン機能・インストールは使えません）。

## 注意

- 修正版 PSD は別ファイル（`〜_fixed.psd`）として保存します。元のファイルは必ず残しておいてください。
- 書き出し時の統合画像はレイヤーから作り直します（レイヤー効果は反映されません。Photoshop で開けば正しく再合成されます）。
- .clip の読み込みは CLIP STUDIO PAINT の非公式な解析によるものです。CSP のバージョンによっては読み込めない場合があります。
- 画像素材レイヤー（拡大縮小できる貼り付け素材）は画像を取り出せないため、CSP でラスタライズしてから読み込んでください。

## 更新のしかた（開発者向け）

ファイルを編集して `git push` すると、GitHub Pages が自動で再公開します（1〜2 分）。
オフライン用のキャッシュは「オンライン時は常に最新を取得」する設定なので、利用者側で特別な操作は不要です。
